Функции агента внутри терминала:

Подключение (как в Claude Code):

/key [sk-or-...] — подключить OpenRouter ключ (начинается с sk-or-), сохраняется в браузере, /key clear — удалить
/model [id] — сменить модель: openai/gpt-4o-mini, anthropic/claude-3.5-sonnet и т.д. Список: openrouter.ai/models
/theme — светлая/темная тема
/exit — завершить сессию
/status — состояние сессии: режим, тон, длина, язык, активные флаги
Код-агент (главное отличие от CORE):

/codecheck [код] — проверка синтаксиса: ищет незакрытые теги <>, дубли id, <img> без alt, отсутствие viewport/lang/title, несбалансированные {} в CSS, числовые значения без единиц (px/rem), присваивание = в if, console.log, innerHTML со склейкой (XSS), == вместо ===
  Вывод: ✅ Явных проблем не найдено или ⚠️ список
/preview [код] — предпросмотр верстки в живом iframe (sandbox), белый фон, 240px высота. Сначала делает codecheck, потом рендерит
/css_fix [код/проблема] — исправить CSS. Без ключа — базовая проверка codecheck, с ключом — LLM ищет и чинит отступы, flex/grid, адаптивность, перекрытия, объясняет причину
/html [dark|minimal|game] [описание] — сгенерировать готовую адаптивную страницу одним файлом. Без ключа — локальный шаблон localPage() (темная тема, минимализм или игра-кликер с очками), с ключом — LLM пишет страницу под описание
Остальные 80+ команд из CORE тоже работают в терминале:
/help [команда], /info (показывает кол-во функций), /menu [номер] — категории (КОД, ТЕКСТ, АНАЛИЗ, ТВОРЧЕСТВО, ОБУЧЕНИЕ, УТИЛИТЫ, СЛОЖНЫЕ, ФАЙЛЫ, ЭКОНОМИКА, ИГРЫ, МОНИТОРИНГ, АДМИН, ПОДКЛЮЧЕНИЕ)

Прокачка в терминале (как в Claude Code + геймификация):

XP/coins: need() = level * 500, addXp(n) с x2 бустом boostXp, addCoins(n) с boostCoin, level up ⬆️ Новый уровень: X!
Достижения ACH: first_win (10 монет), win_streak_5 (50), tic_tac_toe_master (100), first_message (5), chatter_100 (30), night_owl (15 за сообщение в 3-6 утра), first_purchase (10), rich_1000 (100), auction_winner (75), spy_first_win (25), master_spy (100), detective (100)
Квесты: questTick() — ежедневный квест, today() ISO, have/need/done, +100 монет за выполнение
Игры: gameEnd(name, win, xp, coins, draw) — считает played/wins, streak, bestStreak
Хаб моделей внутри терминала:

Это и есть Fich AgentCode+ — агент который:

Проверяет код локально без LLM (codecheck)

Почему так разделил?
CORE — чтобы каждый мог скачать и понять что такое FichAI. Это твой GitHub-трафик.
AgentCode+ (терминал) — отдельный продукт для кодеров. Это как Claude Code, но твой. За него люди готовы платить 800-12500₽, потому что он экономит часы: проверил, показал превью, пофиксил CSS.
ULTRA — красивая обертка-лендинг с рангами, чтобы показать масштаб. Цен пока нет, но структура готова.
